# Quantum Setting — Respuestas a objeciones principales

Documento operativo para responder DMs de Quantum Creators. Versión 29/05/2026.

---

## Reglas base

- Responder corto, natural y con baja presión. No escribir pitches largos por DM.
- Si el lead cualifica y muestra intención, moverlo al siguiente estímulo: VSL, llamada o booking.
- Si Alex marcó una fila roja, WhatsApp, OBJ, manual o "no respondas", no enviar DMs automáticos.
- **NQ** = no cualificado: nurturing + rojo + nota NQ. **NI** = no interesado: feedback/closeout + rojo + nota NI.

**Link discovery:** https://www.quantumcreators.es/llamada-de-discovery  
**Video nurturing:** https://youtu.be/yoW6-LMURb8?si=oEgEmdnHe4MnKdCd

## Objeciones y respuestas

### 1. Precio / cuanto cuesta

| | |
|---|---|
| **Cuándo aparece** | El lead pregunta precio, inversión, tarifa o cuánto cuesta antes de explicar su caso. |
| **Respuesta base** | Te lo explico sin problema, pero antes necesito entender tu caso porque no tendría sentido soltarte un precio sin saber si realmente te podemos ayudar. Por eso hacemos la llamada: vemos tu situación, qué estás vendiendo ahora y si encaja. |
| **Siguiente paso / tracking** | No dar precio por DM como default. Si parece cualificado, llevar a llamada y usar el link de discovery. |

---

### 2. Mándame info / explícamelo por aquí

| | |
|---|---|
| **Cuándo aparece** | Pide información general, un resumen largo o que se le explique todo por chat. |
| **Respuesta base** | Te puedo dar contexto por aquí, pero para explicarlo bien necesito entender tu caso. Si te parece, lo podemos hablar a fondo en una llamada en la que, de manera personalizada, veremos tu caso y te daremos el contexto exacto de todo lo que hacemos y de cómo te podemos ayudar. ¿Te envío link para que puedas reservar un hueco? |
| **Siguiente paso / tracking** | Mantenerlo corto. Si cualifica, enviar enlace de llamada o pedir permiso para enviarlo. |

---

### 3. No tengo tiempo

| | |
|---|---|
| **Cuándo aparece** | El lead está ocupado, posterga o usa falta de tiempo como fricción principal. |
| **Respuesta base** | Lo entiendo. ¿Te sería imposible mañana a las {hora}? *Si dice que no:* Vale, ¿qué día te sería menos imposible verlo 20 minutos? |
| **Siguiente paso / tracking** | Buscar un momento concreto. Si da fecha, dejar nota/manual hold y no seguir follow-ups antes de esa fecha. |

---

### 4. Ahora no tengo dinero

| | |
|---|---|
| **Cuándo aparece** | Dice que no puede invertir ahora, no tiene presupuesto o va justo de liquidez. |
| **Respuesta base** | Lo entiendo. En ese caso no te voy a empujar a nada. Si te sirve, podemos verlo igual para que te lleves claro qué haría sentido priorizar ahora y qué no. *Si aún hay fit real:* Lo entiendo. Si te parece, podemos verlo igualmente en una llamada y te llevas claridad sobre qué tendría sentido hacer ahora, aunque no sea trabajar juntos todavía. |
| **Siguiente paso / tracking** | No empujar si no hay capacidad real. Si hay fit e intención, llamada de diagnóstico sin presión. |

---

### 5. Lo miro luego / me lo pienso

| | |
|---|---|
| **Cuándo aparece** | No rechaza pero pide tiempo, dice que lo mirará o que lo pensará. |
| **Respuesta base** | Tiene sentido. En mi experiencia, cuando alguien dice que necesita pensarlo, normalmente significa que tiene alguna duda o preocupación que aún no ha expresado. ¿Hay algo que te esté frenando y que pueda aclararte? *Si solo quiere retomarlo después:* Perfecto, ¿cuándo te viene bien que te escriba para retomarlo? |
| **Siguiente paso / tracking** | Conseguir duda concreta o fecha concreta. Si hay fecha, nota/manual hold. Si no, seguir cadencia cuando toque. |

---

### 6. No me interesa

| | |
|---|---|
| **Cuándo aparece** | Dice que no, que no le interesa, que no es para él, o responde pidiendo archivar. |
| **Respuesta base** | Perfecto, {nombre}. Y por curiosidad, ¿cuál es el motivo por el que nos has seguido entonces? Lo pregunto por si hay algo en lo que te pueda ayudar. |
| **Siguiente paso / tracking** | Marcar rojo y escribir/append NI en notas. No insistir salvo que el lead reabra con una razón concreta. |

---

### 7. No cualifica / no tiene negocio online

| | |
|---|---|
| **Cuándo aparece** | No tiene negocio, solo tiene negocio físico, está empezando, quiere empezar o no tiene oferta online activa. |
| **Respuesta base** | Genial, gracias por responder. En ese caso creo que ahora mismo no tendría mucho sentido que lo viéramos, porque solemos ayudar a gente que ya tiene un negocio u oferta en marcha. Cuando lo tengas más aterrizado, escríbeme por aquí y lo vemos. De todas maneras, te dejo por aquí un vídeo de mucho valor para que puedas ir avanzando mientras tanto: https://youtu.be/yoW6-LMURb8?si=oEgEmdnHe4MnKdCd |
| **Siguiente paso / tracking** | Enviar nurturing con el video en el mismo mensaje, verificar burbuja enviada, marcar rojo y escribir/append NQ. |

---

### 8. Soy setter / closer / busco trabajo

| | |
|---|---|
| **Cuándo aparece** | Escribe para trabajar, vender servicios de setting/closing o preguntar si el equipo está contratando. |
| **Respuesta base** | Ey, ¡gracias por escribir! Ahora mismo tenemos el equipo de setters y closers lleno, así que no estamos incorporando a nadie más. |
| **Siguiente paso / tracking** | Marcar rojo. No abrir discovery ni seguir vendiendo el servicio. |

---

### 9. Ya tengo equipo o agencia

| | |
|---|---|
| **Cuándo aparece** | Tiene agencia, editor, equipo interno o proveedor que ya gestiona marketing/contenido. |
| **Respuesta base** | Tiene sentido. ¿Y ahora mismo estás contento con los resultados que te están trayendo por YouTube o hay algo que sientas que todavía no está funcionando como debería? |
| **Siguiente paso / tracking** | Si aparece dolor o cuello de botella, llevar a llamada. Si está satisfecho y no hay dolor, no forzar. |

---

### 10. Ya hago contenido, ads u otra captación

| | |
|---|---|
| **Cuándo aparece** | Usa otros canales y cree que eso sustituye YouTube o la captación orgánica. |
| **Respuesta base** | Perfecto. La pregunta es si ese canal te está trayendo clientes de forma predecible o si todavía depende demasiado de esfuerzo/manualidad. |
| **Siguiente paso / tracking** | Conectar con previsibilidad de adquisición. Si hay dolor real, llamada. Si no, dejarlo limpio. |

---

### 11. YouTube no es prioridad

| | |
|---|---|
| **Cuándo aparece** | Dice que ahora YouTube no es su foco, que no lo ve prioritario o que está en otra cosa. |
| **Respuesta base** | Entendido. ¿Puedo preguntarte cuál es tu prioridad en este momento? |
| **Siguiente paso / tracking** | Entender prioridad real. Si su prioridad se conecta a captación/ventas, redirigir a llamada. Si no, cerrar o hold. |

---

### 12. Quiere llamada / segundo pulgar después de VSL

| | |
|---|---|
| **Cuándo aparece** | Después de la VSL, el lead envía el segundo 👍, dice que sí, pide el enlace, pide llamada/agenda/reserva, pregunta cómo reservar o muestra intención clara de siguiente paso. |
| **Respuesta base** | ¡Perfecto, {nombre}! Te dejo por aquí el enlace para reservar tu llamada: https://www.quantumcreators.es/llamada-de-discovery — Avísame cuando ya hayas reservado, así puedo enviarte algunos recursos útiles para que los vayas revisando mientras tanto. |
| **Siguiente paso / tracking** | Mover de B a C, marcar B verde y usar Date C de hoy. Link: https://www.quantumcreators.es/llamada-de-discovery |

---

### 13. Fricción con Calendly / no agenda

| | |
|---|---|
| **Cuándo aparece** | Tiene el enlace pero no reserva, no encuentra hueco, se queda en visto o menciona problemas con el calendario. |
| **Respuesta base** | Eyy {nombre}, mañana tenemos un hueco a las {hora}. ¿Te viene muy mal reservar ahí? Si te da problemas el calendario, te creo yo el hueco. Pásame nombre, email, teléfono y un par de horas que te vayan bien. |
| **Siguiente paso / tracking** | En fase C, priorizar resolver fricción de agenda sobre bumps genéricos. Marcar touch C correspondiente. |

---

### 14. Dice que ha reservado pero no aparece

| | |
|---|---|
| **Cuándo aparece** | Afirma que ya agendó, pero no se ve el booking o no coincide el nombre. |
| **Respuesta base** | Buenas {nombre}, no veo tu nombre por aquí. ¿Qué nombre has puesto al reservar un hueco? |
| **Siguiente paso / tracking** | Pedir nombre usado y, si hace falta, apellido/email. No marcar D hasta verificar booking. |

---

### 15. Respuesta negativa u hostil

| | |
|---|---|
| **Cuándo aparece** | Insulto, burla, mala fe o tono que no merece seguir conversación. |
| **Respuesta base** | Todo bien, gracias por responder. |
| **Siguiente paso / tracking** | Marcar rojo. Solo pedir feedback si no va a inflamar la conversación. |

## Tracking en hoja

| Caso | Acción en DM | Hoja |

| No cualifica | Nurturing + video | Rojo + nota NQ |
| No interesado / archivar | Feedback o cierre breve | Rojo + nota NI |
| Setter / closer | Equipo lleno | Rojo |
| Quiere llamada tras VSL | Enviar link discovery | B verde, copiar/mover a C |
| Calendly enviado sin booking | Follow-ups C | Fechas 1C, 2C, 3C… |
| Manual de Alex | No automatizar | Respetar OBJ, WhatsApp, manual, no respondas |
